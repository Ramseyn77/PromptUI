# PromptUI MVP

A free UI component library for developers. Each component includes an interactive preview, source code, and an AI prompt for recreating or modifying it.

## Stack
- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Lucide React
- Local TypeScript data only

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## Structure
- `app/` routes
- `components/` reusable UI and library previews
- `data/` local component catalog
- `types/` shared TypeScript types
- `layouts/` reusable layout wrappers
- `utils/` helpers

## MVP scope
No authentication, payments, database, backend, or user dashboard.
